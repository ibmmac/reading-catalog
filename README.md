# Reading Catalog

A living shelf list and daily reading log for Mitch and his son.

**Books on the shelf:** [catalog.md](catalog.md)  
**What we read each night:** [read.md](read.md)

Covers are stored in [`covers/`](covers/).

Repo: [ibmmac/reading-catalog](https://github.com/ibmmac/reading-catalog)

## How to update it every day

1. Open [read.md](read.md)
2. Add a new date heading at the **top** of the log
3. Fill in what you read and who read it
4. If it is a new book, add a card in [catalog.md](catalog.md) and drop a JPEG in `covers/`

Or send a photo and ask to add it.
